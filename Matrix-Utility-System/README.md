# Matrix Utility System

## Project Description

Matrix Utility System is a C++ based utility application designed to perform common matrix operations efficiently. This project pairs a browser-based interactive demonstration with an example of the fundamental C++ concepts behind matrix input and display.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- C++ (project implementation example)

## Features

- Responsive academic-project website
- Dynamic matrix input generation, supporting dimensions from 1 × 1 through 8 × 8
- Input validation with clear, accessible feedback
- Separate row and column controls for Matrix A and Matrix B
- Responsive mobile navigation

## Matrix Operations

- Matrix addition
- Matrix subtraction
- Matrix multiplication
- Matrix transpose
- Determinants for 2 × 2 and 3 × 3 square matrices
- Formatted matrix display

## How to Run

1. Open the `Matrix-Utility-System` folder in VS Code.
2. Open `index.html`.
3. Install the Live Server extension if necessary.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

The site uses no framework or build step. It can also be opened directly in a browser.
